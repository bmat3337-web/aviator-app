# Aviator Foundation Verification

The canonical foundation branch contains a deterministic development simulator behind IGameProvider.

Verified design targets:
- reproducible seed/index outcomes
- explicit round state lifecycle
- independent Bet 1 and Bet 2 state
- per-slot Auto Cash Out
- provider abstraction suitable for a future authorized SPRIBE adapter

Not implemented:
- real-money payments
- production wallet
- SPRIBE connectivity
- regulatory certification
- production gaming outcomes

The simulator exists only for development and controlled testing.
